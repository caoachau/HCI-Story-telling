# Landmark marker images

Place the original transparent images in this folder. File basenames identify
the landmark; PNG, WebP, AVIF and JPEG are supported. Vite bundles the files for
development and production without a remote image dependency.

| Filename | Landmark |
| --- | --- |
| `con-chim.png` | Cồn Chim, long island with ponds |
| `bien-ba-dong.png` | Biển Ba Động, beach and wind turbines |
| `bao-tang-khmer.png` | Bảo tàng Khmer, triangular facade |
| `den-tho-bac.png` | Đền thờ Bác, red flags and entrance garden |
| `chua-ang.png` | Chùa Âng, orange roof |
| `chua-hang.png` | Chùa Hang, colorful roof and front gate |
| `ao-ba-om.png` | Ao Bà Om, square pond |

The marker keeps the site's existing documentary photograph as a fallback if
the corresponding local icon is unavailable. Replace it with the supplied
original icon to display the cutout diorama design.
