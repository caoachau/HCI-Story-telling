## Audit và kiểm tra

`scripts/audit-unused.mjs` nay đọc graph build thực của cấu hình Vite, thay cho danh sách ba entry ghi cứng. Lệnh không ghi build và không tự xóa. Việc giữ file hỗ trợ phải có đường dẫn cùng lý do cụ thể; đường dẫn giữ nhưng bị thiếu cũng được báo lỗi.

```powershell
npm run audit:unused
node scripts/audit-unused.mjs --output preview/unused-audit.json
```

Kết quả sau dọn: **5 entry, 0 import/tài nguyên thiếu, 0 file dư ngoài danh sách hỗ trợ được giữ**.

Các kiểm tra đã đạt:

- `npm run lint` và production build đầy đủ bằng `npm run build`.
- `tests/app-assets-test.cjs`: bảy ghim bản đồ, năm phần Ao Bà Om, ảnh so sánh và tiến độ cuộn; không có lỗi tài nguyên nội bộ.
- `tests/con-chim-kt01-test.cjs`: 52 kiểm tra, gồm màn riêng, iframe, điều hướng, mở rộng và QR.
- `tests/museo-detail-test.cjs --overview-viewer-only`: 47 kiểm tra trên production preview, gồm ảnh/nội dung, bố cục responsive, bàn phím và đóng/mở cửa sổ.
